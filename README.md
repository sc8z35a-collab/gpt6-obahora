# 朽家 / KUCHIIE

**おばあちゃんが、待っている。**

スマートフォンのブラウザで遊ぶ、一人称ボクセル3Dサバイバルホラー。朽ちた屋敷に隠された3つの護符を集め、追い続けるおばあさんを振り切って最初の玄関から脱出する、フロントエンド完結のゲームです。

## 実装済み

### ゲーム
- Three.js によるリアルタイム3D描画。19×19セルの屋敷、6つの部屋、廊下、家具、窓、写真、散乱した床材。
- 程度を抑えたボクセル形状とプロシージャル・ピクセルテクスチャ。モデル・画像・音声のゲーム素材は外部から購入・ダウンロードせずコードで構築。
- 霧、暖色の懐中電灯、影、赤い廊下灯、寒色の窓明かり、浮遊する埃、画面の粒状感。
- 頭、顎、肩、肘、脚、スカートを分割したおばあさんのリグ。呼吸、首の傾き、歩行、腕振り、裾の揺れ、接近時の襲撃アニメーション。
- 幅優先探索で壁を回り込む追跡AI、視線が通る場合の直接追跡。護符を集めるにつれて追跡速度が上昇。
- プレイヤー・敵の壁衝突、歩行、スタミナ制ダッシュ、懐中電灯の追従と歩行時の揺れ。
- 護符の取得、残数表示、3枚取得後の玄関脱出、捕獲時のゲームオーバー、プレイ時間と取得数、リトライ。
- Web Audio APIで低い環境音、距離・左右感のある敵の足音、プレイヤーの足音、心拍、取得音、捕獲音を生成。
- タイトルでは自動再生しません。「家に入る」のユーザー操作で音声を開始します。タイトルで明示的にミュートにした場合は尊重します。ゲーム中の音量は一時停止→設定から変更できます。

### UI・設定
- 日本語のシネマティックなタイトル、遊び方、恐怖・音・点滅の注意書き。
- スマホ：左ジョイスティック移動、画面右側スワイプ視点、調べるボタン、長押しダッシュ。
- PC：WASD移動、マウス視点（Pointer Lock）、Shiftダッシュ、Eで調べる、Escで停止。Pointer Lock不可の環境ではドラッグによる視点変更も可能。
- 一時停止、再開、タイトル復帰。タブ非表示・ウィンドウフォーカス喪失でも一時停止。
- 描画品質（高画質/軽量）、視点感度、音量、点滅・画面揺れ抑制。抑制設定では接近顔のジャンプスケアも省略。
- 縦画面・横画面レイアウト、セーフなタッチ終了処理、設定ダイアログのフォーカス制御。
- WebGL未対応・コンテキスト喪失・ライブラリ読み込み失敗時の案内。

## データ構造・保存

- 19×19の2次元配列 `grid`：0=歩ける床、1=壁。
- `player`：位置、視点角、スタミナ、経過時間。メモリー内のみ。
- `granny`：3Dボーン相当のGroup、追跡経路、アニメーション状態。メモリー内のみ。
- `items`：3つの護符の位置・表示・取得フラグ。
- `state`：`intro` / `playing` / `paused` / `scare` / `dead` / `escaped`。
- `localStorage['kuchiie-settings']`：`{ quality, sensitivity, volume, reduced }`。端末内の設定だけを保存。保存が禁止された環境でもプレイ可能。
- サーバー・認証・Table API・Cloudflare D1・ユーザーデータ収集は使用していません。
- 進行状況・ハイスコアは保存しません。リロードすると最初からになります。

## 動作環境・描画方針

WebGLが使用できる最近のSafari / Chrome / Edge / Firefoxを想定。スマホの実機性能に応じて設定の「軽量」を利用してください。高画質では影と埃、軽量では低解像度・影なし・埃なしに切り替わります。壁・固定家具・床の破片はInstancedMeshにまとめ、ピクセル比を制限しています。品質・フレームレートは端末依存で、全スマホでの一定FPSは保証していません。

初回読み込みにネット接続が必要です。ゲーム中にAPI通信やサーバー処理は行いません。

## 検証

- 実ページをデスクトップ1280×800、モバイル390×844のブラウザエミュレーションで表示確認。
- 両サイズでタイトルの背景3D、敵、文字、開始ボタン、フッターに重なり・欠落がないことを確認。
- 両サイズでゲーム中の廊下、HUD、PCヘルプまたはモバイルのスティック/アクションボタンの表示を確認。
- 初期化時に全護符とプレイヤーへの経路が存在することを検証。
- 開発用DOMテストで、遊び方、ゲーム開始、移動・ダッシュでのスタミナ消費、玄関のロック、一時停止による時間停止、一時停止中の設定表示・重なり順、品質設定の保存、再開、タイトル復帰、再スタートの初期化を確認。
- JavaScript実行エラーなし。Three.js旧ビルドの非推奨警告とテスト用ソフトウェアGPUの警告は発生しますが、描画・テストは成功しています。
- 実機のマルチタッチ、音の聞こえ方、長時間の温度・FPS、クリアまでの難易度は、実機プレイでの追加確認を推奨します。脱出・捕獲の全経路自動テストは未実施です。

`tests/smoke.js` は通常の `index.html` からはロードしていません。開発時にゲームスクリプトの後へ一時的に追加すると自動テストが実行され、結果がコンソールと `body.dataset.smoke` に出ます。テストは自動でゲームを開始し、描画品質を軽量に変更します。検証後は必ず読み込みを除去してください。
